# Python w automatyce przemysłowej

## Co to jest Python?
Python to język programowania wykorzystywany do automatyzacji zadań, analizy danych oraz tworzenia aplikacji.

## Zastosowania Pythona
- Analiza danych z czujników.
- Automatyzacja powtarzalnych czynności.
- Testowanie oprogramowania.
- Komunikacja z urządzeniami przemysłowymi.
- Tworzenie aplikacji wykorzystujących AI.

## Python a sterowniki PLC
Python może współpracować ze sterownikami PLC za pomocą odpowiednich bibliotek i protokołów komunikacyjnych.

Przykładowym protokołem jest Modbus TCP.

Python nie zastępuje sterownika bezpieczeństwa ani układu sterowania czasu rzeczywistego.

## Narzędzia programistyczne
- Visual Studio Code.
- Python 3.
- Git i GitHub.
- Biblioteki Pythona.

## Przykład zastosowania
Program w Pythonie może odczytywać temperaturę z czujnika, zapisywać wyniki oraz informować o przekroczeniu określonej wartości.
